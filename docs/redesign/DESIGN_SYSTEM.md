# SVETLY — дизайн-система (утверждённое направление A «Рассвет»)

Источник токенов в прототипе: `prototype/concepts/a.css` (+ `prototype/app/app.css` для компонентов приложения). Текущая система продукта (`docs/DESIGN_SYSTEM.md`, Manrope, зелёная палитра) пока не менялась.

## Бренд

- **Знак:** солнце над полями и дорогой в терракотовом квадрате (иконка приложения), отдельно — солнце + три линии.
- **Словесный знак:** «SVETLY», Literata 650, трекинг +0.02 em; подпись «Октябрьский · Светлый» (Golos Text 500, 11 px).
- **Файлы:** `brand/a-logo-{light,dark,mono-black,mono-white}.svg`, `brand/a-app-icon.svg`. Перевод текста логотипа в кривые — при внедрении.
- Минимальный размер знака — 16 px (favicon), охранное поле — ¼ высоты знака.

## Сетка, отступы, поверхности

- Контейнер 1240 px, поля `clamp(16px, 4vw, 32px)`; плитки кабинетов — 12-колоночная сетка, шаг 14 px.
- Отступы: 4 / 8 / 12 / 16 / 24 / 32 / 40 / 56 px.
- Радиусы: 6 (мелкие), 10 (кнопки, поля), 16 (карточки, панели), 999 (чипы, бейджи).
- Границы 1 px `--line`; тень только у «всплывающих» (панель «Сегодня», диалоги).
- Иконки: контур 24 px, линия 1.8, скругления; набор `prototype/assets/icons.svg`.

## Компоненты (в прототипе)

Кнопки (primary / secondary / ghost / danger, 44–52 px) · иконка-кнопка со счётчиком · бейджи статусов (+ «Концепция» пунктиром) · поле, список, текстовая область с ошибкой и подсказкой · поиск с вкладками (из B) · чипы · вкладки · хлебные крошки · заголовок страницы с действиями · карточки: новость (ведущая / строка), объявление, организация, событие, пост, опрос, обращение со шкалой статуса · плитка-виджет и KPI (из B) · таблица (на mobile → карточки) · диалог / нижняя шторка · подтверждение опасного действия со словом · боковое меню-шторка · нижнее меню · тост · скелетон, пустое состояние, ошибка, «Нет доступа», «Войдите».

## Фото и иллюстрации

Настоящие снимки посёлка с согласия людей, тёплая естественная цветокоррекция; без стоковых сцен. Пока фото нет — тёплые плашки-заглушки. Иллюстрации — только знак-солнце и линии горизонта.

## Доступность

WCAG 2.2 AA: контраст ≥ 4.5:1, фокус 3 px `--sky`, цели нажатия ≥ 44 px, `prefers-reduced-motion`, ссылка «К содержанию», заголовок `h1` на каждом экране, диалоги с `aria-modal` и закрытием по Esc.
