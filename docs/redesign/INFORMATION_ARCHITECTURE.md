# SVETLY — информационная архитектура (PHASE C)

## Верхний уровень: 5 разделов вместо 13

| Раздел | Что объединяет (модули продукта) | Адрес в прототипе |
| --- | --- | --- |
| Главная | Сводка: сегодня, быстрые действия, всё понемногу | `#/` |
| Новости | Новости редакции | `#/news` |
| Объявления | Объявления + вакансии + потеряно/найдено — вкладки одного каталога | `#/ads?tab=…` |
| Услуги и бизнес | Организации + услуги + предприниматели (К) + справочник + места | `#/catalog?tab=…`, `#/directory` |
| Сообщество | Лента и группы + опросы + обращения + события | `#/community?tab=…`, `#/events`, `#/issues` |

Глобальные элементы шапки: поиск (иконка, страница с вкладками по разделам), «Разместить», сообщения и уведомления (со счётчиком), кабинет, «Админка» для сотрудников.

## Навигация

- **Desktop ≥ 901 px:** горизонтальное меню из 5 пунктов, справа — действия.
- **Tablet и mobile ≤ 900 px:** логотип + кнопка меню (шторка справа: 5 разделов, «Ещё»: события, справочник, места, обращения, опросы, вакансии, находки, поиск).
- **Mobile ≤ 640 px:** нижняя панель: Главная · Разделы (шторка) · Разместить · Сообщения · Кабинет/Войти.

## Единая точка создания

`#/submit` → объявление · вакансия · потеряно/найдено · проблема (обращение) · пост в группе · организация/услуга. Гость получает экран «Войдите» и после входа возвращается на исходную страницу (`?next=`).

## Кабинеты

- **Кабинет жителя** `#/me/*` — одна оболочка с меню: Обзор, Мои публикации, Обращения, Избранное, Сообщения, Группы, Уведомления, Рекомендации, Профиль и безопасность.
- **Кабинет бизнеса** `#/biz/*` — та же оболочка, переключатель «Житель / Бизнес» для владельцев карточек. Заявки жителей переезжают сюда из кабинета жителя.

## Админ-платформа (группы вместо плоских 18 пунктов)

Обзор · **Модерация** (очередь, жалобы) · **Контент** (новости, события, организации и услуги, справочник, категории) · **Сообщество** (обращения, опросы, группы и лента) · **Бизнес** (заявки) · **Люди** (пользователи и роли) · **Система** (аналитика, журнал аудита, настройки и функции).

Пункты видны по правам роли; права проверяет сервер.

## Соответствие текущим маршрутам продукта (для будущего внедрения)

| Сейчас | Предлагается |
| --- | --- |
| `/services`, `/organizations`, `/directory`, `/map` | `/catalog` с вкладками (+ редиректы) |
| `/jobs`, `/lost-found` | вкладки `/announcements` |
| `/feed`, `/groups`, `/polls`, `/issues` | `/community` с вкладками; карточки остаются |

| 18 пунктов `/admin/*` | те же страницы, сгруппированное меню; единая очередь — новый API |

Это план для этапа внедрения после отдельного разрешения. Сейчас маршруты продукта не менялись.
