# SVETLY — перечень экранов (PHASE C)

Направление: A «Рассвет» + из B поиск с вкладками и плотные плитки-виджеты для кабинетов и админки.

Статус в продукте: **Р** — есть, **Ч** — частично, **К** — только концепция (в прототипе помечена «Концепция»).
Состояния: **З** — загрузка (скелетон), **П** — пусто (подсказка + действие), **О** — ошибка (повтор), **М** — модерация (статус-бейджи). Любой список в прототипе переключается панелью «Данные».
