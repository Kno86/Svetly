# SVETLY — концепции бренда (PHASE B)

Статус: контрольная точка 2, выбор направления. Рабочее приложение не менялось.

Материалы — изолированный статический прототип `docs/redesign/prototype/` (без API, базы и реальных действий):

| Файл | Что это |
| --- | --- |
| `prototype/index.html` | Выбор концепции |
| `prototype/concepts/a.html`, `b.html`, `c.html` | Бренд-борды: логотип, иконка, палитра, типографика, компоненты, правила, главная в desktop и mobile |
| `prototype/concepts/a-home.html`, `b-home.html`, `c-home.html` | Главная страница, адаптивная (360–1440+) |
| `brand/*.svg` | Логотипы (светлый/тёмный фон, монохром чёрный/белый) и иконки приложения |
| `screens/concept-*-home-{desktop,mobile}.png` | Скриншоты 1440 и 390 px |

Запуск: `cd docs/redesign/prototype && python3 -m http.server 8090`, затем `http://127.0.0.1:8090/`.

Шрифты — самостоятельно размещённые OFL-1.1 (Fontsource): Literata, Golos Text, Unbounded, Onest, Jost, с кириллицей. Лицензии — `prototype/assets/fonts/LICENSE-*.txt`.

## Общее для всех концепций

- Новая структура из аудита: 5 разделов (Главная, Новости, Объявления, Услуги и бизнес, Сообщество), поиск, единая кнопка «Разместить», кабинет.
- Мобильная нижняя панель: Главная · Разделы · Разместить · Сообщения · Кабинет.
- Главная: поиск с подсказками-разделами, 4 быстрых действия, новости, объявления, услуги, афиша, сообщество (опрос, обращение со статусом, группы), блок для предпринимателей.
- Честность: плашка «данные вымышлены», пометка «пример» на записях, «концепция» на функциях, которых нет (статистика бизнеса).
- Доступность: все пары цветов текста — не ниже WCAG AA (4.5:1), фокус 3 px, зоны нажатия от 44 px, без горизонтального скролла на 390 px (проверено).

## A «Рассвет» — тёплый редакционный

- **Идея:** хорошая местная газета. Знак — солнце над полями и дорогой.
- **Логотип:** знак в терракотовом квадрате + «SVETLY» антиквой + подпись «Октябрьский · Светлый».
- **Палитра:** Закат `#B4441E` (основная, белый текст 5.55:1) · Солнце `#F2B441` (акцент, не для текста) · Небо `#2F5D7C` · Шалфей `#4E6E4B` · Ink `#24201C` · Paper `#FAF6EF`. Состояния: успех `#2E7D4F`, предупреждение `#8A5600`, ошибка `#B42318`, инфо `#2F5D7C`.
- **Шрифты:** Literata (заголовки) + Golos Text (интерфейс и текст, 17 px).
- **Поверхности:** бумажный фон, белые карточки, граница 1 px, радиусы 6/10/16, прямоугольные кнопки.
- **Композиция:** журнальная — ведущая новость + список, таймлайн событий, каталог списком.

## B «Окно» — современный продуктовый

- **Идея:** свет в окне — дом, где кто-то есть. Знак — 4 окна, одно горит.
- **Логотип:** знак + «svetly» строчными, Unbounded.
- **Палитра:** Night `#0E1330` · Кобальт `#2E46D8` (основная, 7.04:1) · Лампа `#FFC23D` (CTA на тёмном) · Мята `#156B55` · Bg `#F4F5F9`. Состояния: успех `#13795B`, предупреждение `#8F5B00`, ошибка `#C8283C`, инфо `#2E46D8`.
- **Шрифты:** Unbounded (заголовки) + Onest (интерфейс и текст, 16 px).
- **Поверхности:** светлый фон, белые плитки, ночные панели для главного, радиусы 8/12/20, кнопки-таблетки.
- **Композиция:** тёмный hero с поиском по вкладкам, bento-сетка на главной, дашбордная логика.

## C «Берёза» — сибирский минимализм, швейцарская сетка

Добавлена по просьбе владельца как кардинально другой вариант.

- **Идея:** снег, чёрная кора берёзы, красная ягода рябины. Строгая графика вместо «уютных» карточек.
- **Логотип:** квадрат-рамка с фрагментом коры и ягодой + кириллический «СВЕТЛЫЙ» капсом (Jost), подпись «SVETLY · Октябрьский».
- **Палитра:** Кора `#141414` (основная, кнопки) · Рябина `#C7202B` (акцент, 5.72:1) · Иней `#0B6596` · Хвоя `#1E6B4F` · Snow `#FFFFFF` · Frost `#E9EEF0`. Состояния: успех `#1E6B4F`, предупреждение `#8A5A00`, ошибка `#C7202B`, инфо `#0B6596`.
- **Шрифт:** один — Jost (геометрический гротеск, близок к конструктивизму); заголовки капсом.
- **Поверхности:** без теней и скруглений, разделение линиями 1–2 px, кнопки — прямоугольники с рамкой.
- **Композиция:** на desktop — левая колонка навигации, нумерованные разделы 01–04, списки строками, как указатель. На мобильном — верхняя панель и нижнее меню.

## Сравнение

| Критерий | A «Рассвет» | B «Окно» | C «Берёза» |
| --- | --- | --- | --- |
| Характер | Тёплый, спокойный, «свой» | Яркий, современный, технологичный | Строгий, графичный, «северный» |
| Узнаваемость знака в 16 px | Хорошая (солнце + линии) | Отличная (4 квадрата) | Средняя: мелкие штрихи коры теряются, ягода остаётся |
| Длинные русские заголовки | Хорошо: антиква компактна | Хуже: Unbounded широкий, на 360 px переносы чаще | Хорошо в строчных; капс в H1 — только для коротких фраз |
| Чтение новостей и длинных текстов | Сильная сторона | Нормально | Хорошо: спокойные списки |
| Кабинеты и админка | Нужно больше дисциплины в плотных таблицах | Естественно ложится на дашборды | Отлично ложится на таблицы и списки |
| Аудитория разных возрастов | Привычнее старшим жителям | Ближе молодым и предпринимателям | Нейтрально; может казаться холодным |
| Риск «шаблонности» | Ниже, чем у текущего зелёного | Тёмный hero + bento — популярный приём | Низкий для локальной платформы |
| Отличие от текущего бренда | Полное: новая палитра, шрифты, знак | Полное | Полное, включая структуру страниц |

## Рекомендация

**A «Рассвет»** как основа. Платформа прежде всего про новости, объявления и соседей — тёплая редакционная подача вызывает доверие у всех возрастов, антиква делает продукт узнаваемым и не похожим на типовой UI-шаблон, длинные русские заголовки ложатся лучше.

Из B предлагаю взять: поиск с вкладками по разделам и плотные плитки-виджеты для кабинетов и админки (в палитре A).

C — самый смелый и самый «местный» по образу (берёза, Сибирь), лучший для плотных списков, кабинетов и админки, но холоднее по настроению и требует хороших фотографий. Если вам ближе B или C — полный прототип можно сделать на них; рекомендация не обязательна.

## Ограничения

- Логотипы — концепт: в SVG словесный знак набран шрифтом, а не переведён в кривые. Перевод в кривые и финальная отрисовка — после выбора.
- Фото нет: вместо них цветные заглушки с подписью. Нужны собственные снимки посёлка с правом использования.
- В C знак мельче читается в 16 px — при выборе C упрощу его для favicon.
- Это только главная и бренд-борд. Остальные экраны — в PHASE C после выбора.
