# Выгрузка данных и удаление аккаунта

Житель сам скачивает свои данные и удаляет аккаунт: «Личный кабинет» → вкладка «Мои данные». Основание: право субъекта на доступ к своим персональным данным и на их удаление (152-ФЗ, ст. 14 и 21). Юридический текст политики всё равно должен проверить юрист (см. `docs/LAUNCH.md`, раздел 5).

## API

| Метод  | Адрес            | Что делает                                                                                       |
| ------ | ---------------- | ------------------------------------------------------------------------------------------------ |
| `GET`  | `/api/me/export` | JSON-файл с данными пользователя, `Content-Disposition: attachment`, `Cache-Control: no-store`   |
| `POST` | `/api/me/delete` | Тело `{ "password": "…", "confirm": "УДАЛИТЬ" }`. Удаляет аккаунт без возможности восстановления |

Оба адреса доступны только после входа. На `POST` действует общая проверка `Origin` (CSRF).

## Выгрузка

В файл входят профиль, роли, объявления, вакансии, находки, обращения с ответами, посты, комментарии, отметки «Нравится», созданные группы и участие в группах, избранное, голоса, регистрации на события, жалобы, заявки организациям, карточки организаций, **свои** сообщения, настройки уведомлений, интересы и сведения о загруженных фото.

Тексты других людей (их сообщения, ответы на заявки) в файл не входят. Действие записывается в журнал: `account.exported`.

## Удаление

Проверки:

1. Пароль. После 5 неверных паролей за 15 минут сервер отвечает `429 TOO_MANY_ATTEMPTS`. Каждая неудача пишется в журнал: `account.deleted` / `failure`.
2. Слово `УДАЛИТЬ` в поле `confirm`.
3. У аккаунта нет служебных ролей. Иначе `409 STAFF_ACCOUNT`: сначала администратор снимает роли. Так платформа не может потерять последнего администратора.

Что происходит в одной транзакции:

| Данные                                                                                                                               | Результат                                                                                                                        |
| ------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| Объявления, вакансии, находки, обращения с ответами, жалобы, заявки организациям, голоса, регистрации, избранное, отметки «Нравится» | удаляются                                                                                                                        |
| Посты, комментарии, сообщения, участие в группах и переписках, сессии, способы входа, уведомления, блокировки, интересы              | удаляются каскадом вместе с пользователем                                                                                        |
| Загруженные фото                                                                                                                     | удаляются строки `media_assets` и файлы                                                                                          |
| Неопубликованные карточки организаций (заявки)                                                                                       | удаляются                                                                                                                        |
| Опубликованные карточки организаций                                                                                                  | остаются в каталоге без владельца (`ownerId = null`). Отложенные правки сбрасываются, решение о карточке принимает администратор |
| Созданные группы                                                                                                                     | переходят самому давнему активному участнику, он становится `owner`. Группа без участников удаляется                             |
| Переписки                                                                                                                            | история собеседника остаётся                                                                                                     |
| Ответы сотрудника в обращениях                                                                                                       | автор обнуляется                                                                                                                 |
| Журнал аудита                                                                                                                        | остаётся: в нём нет email и паролей. Сам факт удаления пишется как `account.deleted` / `success`                                 |
| Аналитика                                                                                                                            | остаётся: в ней только псевдонимный хэш                                                                                          |

Повторная регистрация с тем же email создаёт новый пустой аккаунт.
