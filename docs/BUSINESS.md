# Кабинет бизнеса

## Процесс размещения

1. Владелец (любой вошедший пользователь) подаёт заявку в `/business/new` → `POST /api/business/organizations`.
2. Сервер проверяет данные и создаёт карточку со статусом `pending`, `ownerId` = заявитель. Не больше 3 заявок на проверке одновременно.
3. Владелец видит статус в `/business`.
4. Администратор (`business.review`) видит заявку в `/admin/business` (`GET /api/admin/business/applications`).
5. Решение: `approve` → `published`; `request_info` → `needs_info`; `reject` → `rejected`. Для отказа и уточнения причина обязательна, её видит владелец. Всё пишется в журнал аудита.
6. Отметка «Данные проверены» ставится отдельно (`organizations.verify`, PHASE 5).

## Изменения опубликованной карточки

- `PATCH /api/business/organizations/:id` для опубликованной карточки сохраняет `pendingChanges`. Публично остаётся старая версия.
- Одобрение применяет изменения. Если поменялись название, телефон, сайт или адрес, отметка `verified` снимается до повторной проверки.
- Неопубликованную карточку владелец правит напрямую, она снова уходит на проверку.

## Заявки жителей

- На карточке с владельцем есть кнопка «Оставить заявку» (`acceptsInquiries`; сам `ownerId` публично не отдаётся).
- `POST /api/organizations/:id/inquiries` — только вошедшим, не владельцу, не больше 10 неотвеченных от одного жителя.
- Заявки видят только отправитель (`/account/community`) и владелец (`/business/:id`). Ответ — `POST /api/business/inquiries/:id/reply`.

## Чего нет и почему

Статистики просмотров, отзывов, рейтингов, продвижения, тарифов и сотрудников компании нет: не показываем данные, которых нет. Чат появится с модулем сообщений (PHASE 7). Категорию карточки назначает редакция в CMS.

## Статистика карточки

`GET /api/business/organizations/:id/stats?days=7|30|90` (только владелец, иначе 404) и блок
«Статистика» на странице `/business/cards/:id`. Сутки считаются по `Asia/Novosibirsk`.

| Показатель           | Источник                                                           | Точность |
| -------------------- | ------------------------------------------------------------------ | -------- |
| Просмотры карточки   | `page_view` с путём `/organizations/<slug>` или `/services/<slug>` | оценка   |
| Переходы к контактам | `contact_click` с теми же путями (телефон, email, сайт, карта)     | оценка   |
| Заявки жителей       | таблица `business_inquiries`                                       | точно    |

Просмотры и клики — события браузера: они не отправляются при Do Not Track или Global Privacy
Control и удаляются по сроку хранения аналитики (см. `docs/ANALYTICS.md`). Посетители не
идентифицируются: владелец видит только суммы по дням. Если событий нет, выводится 0.

## Отзывы об организациях

Отзывы проходят премодерацию: житель пишет отзыв, он попадает в единую очередь `/admin/moderation`
(вид «Отзывы», право `moderation.community`) и становится виден только после одобрения.

| Endpoint                                     | Кто                 | Что делает                                                |
| -------------------------------------------- | ------------------- | --------------------------------------------------------- |
| `GET /api/organizations/:id/reviews`         | все                 | опубликованные отзывы, `summary`, свой отзыв (`mine`)     |
| `POST /api/organizations/:id/reviews`        | житель, не владелец | создать или изменить свой отзыв; снова уходит на проверку |
| `DELETE /api/organizations/:id/reviews/mine` | автор               | удалить свой отзыв                                        |
| `POST /api/moderation/reviews/:id/:decision` | модератор           | `approve`, `reject` или `unpublish` (с причиной)          |

Правила:

- один отзыв от жителя на организацию, оценка 1–5, текст 20–2000 символов;
- владелец не может оценить свою организацию; не больше 5 отзывов на проверке одновременно;
- средняя оценка показывается только при 3 и более опубликованных отзывах, иначе только количество;
- автор виден по имени, ссылка на профиль — только если профиль открыт; email не возвращается;
- модератор отклоняет отзывы с персональными данными, оскорблениями и непроверяемыми обвинениями.
  Окончательные правила модерации отзывов должен утвердить юрист (риск ст. 152 ГК РФ).

Отзывы удаляются вместе с аккаунтом автора и входят в выгрузку своих данных.
