# SVETLY — бренд (концепт PHASE 2)

> **Статус: рабочий концепт на утверждение владельцем.** Это не окончательный и не юридически проверенный бренд.
> До коммерческого использования нужна проверка на сходство с зарегистрированными товарными знаками (Роспатент / ФИПС)
> и, при необходимости, регистрация. Уникальность знака не заявляется.

## Идея знака

Скруглённый квадрат цвета Deep Forest. Внутри — солнце (Warm Gold), холм (Forest), две ели (Leaf Green), дом и
плавная дорога (Ivory). Смысл: свет и природа, дом и путь к нему — жизнь рядом с домом.

Надпись `SVETLY` набрана Manrope ExtraBold (SIL Open Font License 1.1) и переведена в векторные контуры.
Межбуквенный интервал +6 %. Для отображения шрифт не нужен.

## Файлы

Все файлы генерируются одной командой `pnpm --filter @svetly/web run brand:generate`
из скрипта `apps/web/scripts/generate-brand.mjs`. Геометрия знака задаётся в нём один раз.

| Файл (`apps/web/public/brand/`)                         | Назначение                                                 |
| ------------------------------------------------------- | ---------------------------------------------------------- |
| `svetly-logo.svg`                                       | основной логотип: знак + надпись, светлый фон              |
| `svetly-logo-vertical.svg`                              | вертикальная компоновка                                    |
| `svetly-logo-on-dark.svg`                               | цветной логотип для тёмного фона (плашка знака — Forest)   |
| `svetly-logo-mono.svg`, `svetly-mark-mono.svg`          | монохром Deep Forest для светлых фонов, печати, гравировки |
| `svetly-logo-inverse.svg`, `svetly-mark-inverse.svg`    | инверсия Ivory для тёмных фонов и фотографий               |
| `svetly-mark.svg`                                       | знак приложения без текста                                 |
| `svetly-mark-small.svg`                                 | упрощённый знак для 16–48 px (без дома и елей)             |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | иконки PWA / Android (maskable — с safe zone 80 %)         |
| `social-avatar-400.png`                                 | аватар для VK / Telegram                                   |
| `og-image.png`                                          | превью ссылок 1200×630                                     |

Next.js подключает автоматически: `app/favicon.ico` (16/32/48), `app/icon.svg` (упрощённый знак),
`app/apple-icon.png` (180×180) и `app/manifest.ts`.

В интерфейсе логотип выводится компонентом `components/brand/Logo.tsx` в виде inline SVG
(варианты `color`, `on-dark`, `mono`, `inverse`, компоновка `horizontal` или `mark`). Компонент берёт контуры
из сгенерированного файла `components/brand/logo-geometry.ts`.

## Правила использования

- Минимальная высота знака — 16 px (упрощённая версия), горизонтального логотипа — 24 px.
- Охранное поле — не меньше 1/4 высоты знака со всех сторон.
- На светлом фоне — основной или монохромный вариант. На тёмном фоне или фото — `on-dark` или инверсный.
- Не перекрашивать элементы знака, не растягивать, не добавлять тени и обводки, не набирать надпись другим шрифтом.

## Что ещё нужно до финала

1. Решение владельца: принять концепт или доработать (возможно — сравнить 2–3 альтернативы).
2. Проверка товарных знаков перед коммерческим использованием.
3. Печатные носители (QR-постер, рекламные форматы) — по запросу, после утверждения знака.
